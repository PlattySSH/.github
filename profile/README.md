### What we're building

Northlight makes tools for people who run servers. The first one is Boreal, a fast, native SSH client and terminal for Windows: hosts, keys, tunnels, SFTP and snippets in one window. It's written in Go and drawn on the GPU, with a terminal built from scratch. Backups come next. No accounts, no telemetry, and everything you save stays encrypted on your machine.
