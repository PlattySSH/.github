# Getting help

- **How do I...?** Start with the [documentation](https://plattyssh.github.io/docs/).
- **Something is broken**: open a [bug report](https://github.com/PlattySSH/platty/issues/new?template=bug_report.yml).
- **An idea**: open a [feature request](https://github.com/PlattySSH/platty/issues/new?template=feature_request.yml).
- **A security problem**: follow the [security policy](SECURITY.md) and report it privately.
