# Getting help

- **How do I...?** Start with the [documentation](https://northlighthq.github.io/plattyssh.github.io/docs/).
- **Something is broken**: open a [bug report](https://github.com/northlighthq/boreal/issues/new?template=bug_report.yml).
- **An idea**: open a [feature request](https://github.com/northlighthq/boreal/issues/new?template=feature_request.yml).
- **A security problem**: follow the [security policy](SECURITY.md) and report it privately.
